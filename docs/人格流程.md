# 人格流程

> 一份角色 = `characters/<角色id>/` 一个目录。代码里没有任何地方写死「角色是谁」，
> 除了 `ellen-lover` 那张老卡的专用分支（见 §5）。新增角色只加目录，不改代码。

---

## 1. 一条消息进来，人格是怎么拼出来的

```
用户消息
  │
  ├─ 记忆层 memory-runtime ──────────► 记忆包 packet
  │    · persona.base / knowledge      角色包.json
  │    · relationship 状态             关系库（阶段 + 三轴数值 + 心情）
  │    · dialogueState                 角色 id / guidance 文件名 / 恋爱档开关
  │
  ├─ 表达层 dialogue-guidance ───────► 表达指导 b
  │    · 基础规则（通用节奏 / 角色自己的「当轮接话.md」）
  │    · 人格底色（persona）
  │    · 当前关系表达（按阶段取一句）
  │    · 近期重复/追问观察
  │
  └─ 组装 src/chat-service.cjs ──────► 发给模型
       packet + history(30) + common + fixed + dynamic
```

最终结构（`src/chat-service.cjs` 里 `dynamic:[b, ...]` 那一段）：

| 槽位      | 内容                                            | 来源 |
| --------- | ----------------------------------------------- | ---- |
| `packet`  | 记忆包                                          | memory-runtime |
| `history` | 近 30 条原话                                    | 本地会话 |
| `common`  | `CHAT_GUIDANCE` + `CHINESE_REPLY_INSTRUCTION`    | 通用 |
| `fixed`   | `sentenceReplyGuidance(characterId)` 句式控制     | 按角色 |
| `dynamic` | `b`（表达指导）、情绪、沟通规则、笔记            | 逐轮变化 |

改人格 = 改 `dynamic[0]` 的内容，不是改 prompt 模板。

## 2. 表达层怎么拼（`src/dialogue-guidance.cjs`）

`buildDialogueGuidance({state, messages})` 按顺序 push 段落，最后 `join("\n")`：

1. **基础层**
   - `ellen-lover` → `characters/ellen-lover/当轮接话.md`
   - `ellen` → `characters/ellen/当轮接话.md`
   - 其他角色 → `角色包.json` 的 `guidance` 指向的文件
   - 都没有 → 通用 `RHYTHM_GUIDANCE + CONVERSATION_GUIDANCE`
2. **专用层**（仅 `ellen-lover`）：颜文字规则、时钟、恋人卡提示、催睡抑制
3. **数据驱动层**（除 `ellen-lover` 外所有角色）
   - 时钟
   - `persona.base`（怎么说话）
   - `persona.knowledge`（知道什么）
   - `当前关系表达：<阶段名>。` + 该阶段的一句行为说明
   - 阶段进度百分比（靠近下一阶段的程度）
   - 「阶段只影响亲疏、不改事实判断」
   - 恋人档说明（`romance && stage==="lover"`）
4. **观察层**：近期重复短语、连续追问 → 提示换接法

`ellen` 的 base/knowledge 已搬到 `角色包.json`，代码里的同文案只是兜底。

## 3. 好感度

### 3.1 三个阶段轴 + 心情

| 轴 | 含义 |
| --- | --- |
| `familiarity` 熟悉 | 聊过多少、是否接得住 |
| `trust` 信任 | 是否可靠、说到做到 |
| `closeness` 亲近 | 是否愿意分享、示弱 |

心情 `MOODS = neutral / warm / guarded / annoyed / concerned / hurt`，90 分钟半衰，最多 6 小时。

### 3.2 分值怎么来

每条用户消息经评估模型打分，结果落库：

- `gradeUnits = [0, 0.25, 0.75, 1.5]`：四档
- `positiveMultiplier = 2`：正向翻倍
- `dailyCap = 3`：**负向**每日上限；`positiveDailyCap = null`：正向不设上限
- `repeatWeights = [1, 0.5, 0.25, 0]`：72 小时内同一类事重复，收益递减到 0
- 评估类型 `KINDS`：理解、欣赏、可靠、合作、关心、修复、边界、不尊重、纠正、无

### 3.3 阶段与门槛

`POLICY.stageGates`（默认值，可被角色包覆盖）：

| 阶段 | key | familiarity | trust | closeness | 事件数 | 天数 |
| --- | --- | --- | --- | --- | --- | --- |
| 陌生 | `learning` | 起点 | — | — | — | — |
| 相识 | `acquainted` | 3 | — | — | 2 | 0 |
| 熟悉 | `familiar` | 12 | — | — | 6 | 3 |
| 信赖 | `trusted` | 25 | 20 | — | 15 | 7 |
| 亲近 | `close` | 45 | 40 | 35 | 30 | 14 |
| 恋人 | `lover` | 60 | 55 | 50 | 45 | 21 |

- 从高到低逐级判定，第一个全满足的就是当前阶段。
- `trust <= -10 || closeness <= -10` → `strained`（有待修复），优先于一切。
- `lover` 需要 `romance === true`，否则跳到 `close`。
- 全部不满足 → `learning`（陌生）。

### 3.4 留的接口（后续细化就改这里）

角色包 `relationship` 段：

```json
"relationship": {
  "allowRomance": true,      // 能不能升到恋人档
  "scoring": true,           // 关掉则只读不评分
  "stageGates": {            // 可只覆盖想改的那几个字段
    "lover": { "familiarity": 60, "trust": 55, "closeness": 50, "events": 45, "days": 21 }
  }
}
```

- `stageGates` 与默认值 **浅合并**：没写的字段沿用默认。
- 数值层配置在 `memory/src/relationship-policy.cjs` 的 `POLICY`（全局默认）。
- 恋人卡（`ellen-lover`）走 `established_lovers`：起始即恋人，数值只记录启用后的相处。

**还没接的**：阶段变化的仪式感反馈、升级提示文案、每日上限的正向版本、心情对分值的反作用。位置都留好了，等点名。

## 4. 新增一个角色（5 步）

1. 复制 `characters/_模板/` → `characters/<你的角色id>/`
2. 把 `角色包.json`、`原作记忆.json`、`世界设定.json` 里的 `id` / `characterId` 全改成新 id
   - id 规则：任意非路径字符，禁 `/ \ : * ? " < > |`、不能以 `.` 开头、不能含 `..`
3. 写 `当轮接话.md`（怎么说话）和 `角色包.json` 的 `persona.base` / `persona.knowledge`（知道什么）
4. 换 `appearance` / `mascot` 的图（`uiBase` 指到自己的素材目录），头像 id 用 `[a-z0-9-]`
5. 把 id 加进角色可选列表（`characters/active-card.json` 与 `CARD_IDS`，见 `src/character-pack.cjs`）

三个 JSON（原作记忆/表达样本/世界设定）即使为空也必须在，缺一个这张卡就加载不出来。

## 5. 已知边界

- `ellen-lover` 保留独立分支（专用 guidance、时钟、颜文字、催睡检测），不参与数据驱动层。要统一是下一步的事。
- `ellen-lover` 目录里没有那三个 JSON，所以 `loadCharacterPack("ellen-lover")` 返回 `null`，走 `coreOverride` + `cardContext`，这是原有设计。
- 图片生成、语音、桌面小人门禁都不在这条链上。
