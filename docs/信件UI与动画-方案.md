## 一、右键隐藏 → 收进右边栏

不是"消失"，是"收起来"。三拍，总 720ms：

| 拍 | 动什么 | 时长 | 缓动 |
|---|---|---|---|
| ① | 浮块 `scale(1) → .18` + `opacity → 0` | **320ms** | `cubic-bezier(.4,0,1,1)`（先快后慢地缩下去） |
| ② | 一个极小的信物从原位置飞向右边栏底部 | **400ms** | `cubic-bezier(.6,0,.4,1)`（**先快后慢**，按你说的） |
| ③ | 右边栏底部长出一行窄条 | 180ms 淡入 | ease-out |

右边栏底部那一行：

```
┌──────────────────┐
│  ✉  信     3     │   ← 12px，灰，hover 时亮
└──────────────────┘
```

- 只有一个数字（未读数），不显示标题，不抢注意力。
- **点它 = 把浮块放回桌面**（原位置，反向 400ms + 320ms 放大回来）。
- 便签被隐藏也一样，长出一行 `📄 便签`，点了回去。
- 两样都被隐藏时，就是两行，贴着栏底。

平时（没隐藏时）右边栏**就是空着的** —— 时钟和相处纪念下面直接是空白，直到有人把东西收进去。

## 二、桌面信封点开的顺序

信封浮块只是一个入口，点它之后按这个顺序走：

```
点信封
  │
  ├─ 有未读？
  │    ├─ 是 ─→ 打开【未读里阶段最低的那一封】（= 最早的一封）
  │    │        读完 → 底部出现按钮：
  │    │           ├─ 还有未读 → [下一封 →]
  │    │           └─ 没有未读了 → [查看全部信 →]
  │    │
  │    └─ 否 ─→ 打开【信匣】（全部信的方块网格）
```

- **多封未读先给最低的那封**：按你的话做。逻辑上也对 —— 信是顺着时间的，倒着读会乱。
- 「下一封」就是按阶段顺序往后一封，不是"下一封未读"（因为已经排好序，未读的自然在前）。
- 读一封就标已读，封蜡变空心。
- 关掉卡片后，桌面信封上的数字/封蜡跟着更新；全部读完时信封下方小字从「亲近 · 未读」变成「亲近 · 已读」。

      ╰────────────────╯              ╰────────╯
  ┌──────────────────────────────────────────────┐
  │                                    ╭───╮    │ ← 同一个蝴蝶结
  │  2026年10月29日                              │
  │                                              │
  │  你开始跟我说"今天不顺"了。                    │
  │  以前你都只回"嗯""好"。                       │
  │  那天你说了好长一段，我把那段话看了两遍。        │

  │                  ——你的、就差一句话的艾莲      │

## 六、阶段推进规则（这条改了核心算法）

### 6.1 双条件

```
升到下一阶段 = （累计点数 >= 该阶段门槛） 且 （当前阶段内消息数 >= 30）
```

- **天数只加点数，不推阶段**。没有消息的纯天数，永远过不了 30 条这条线。
- **点数满了也不行** —— 卡在 29 条就是不动。
- 一条消息都没有的阶段：不写那封信，也不推进（你说"一条信息都没有不进入下一阶段"）。

### 6.2 点数怎么涨（已定）

- 每收到一条消息（你或她）：**+1**
- 每个聊过天的日子（当天至少有 1 条）：**+3**
- 什么都不做的日子：**0**（不加不减）

### 6.3 门槛不变，加了 30 条约束后仍是 30 天

天天聊 10 条 = 13 点/天：

| 阶段 | 累计点数门槛 | 只按点数到达 | 加 30 条约束后 |
|---|---|---|---|
| 相识 | 25 | 第 2 天 | **第 3 天**（第 2 天只有 20 条） |
| 熟悉 | 80 | 第 7 天 | 第 7 天 |
| 信赖 | 160 | 第 13 天 | 第 13 天 |
| 亲近 | 280 | 第 22 天 | 第 22 天 |
| **恋人** | **390** | **第 30 天** | **第 30 天** |

只有第一档被 30 条卡了一下（延后 1 天），后面全是点数主导。**总数还是 30 天**。

聊得多自然更快（一天 50 条 = 8 天到恋人），聊得少就更慢 —— 这是你要的效果。

### 6.4 判定时机

每次聊完一轮（消息落库后）算一次，不轮询。达标就当场写那封信，同时桌面浮出信封。

## 七、动画

| 环节 | 动什么 | 时长 / 缓动 |
|---|---|---|
| 浮块出现 | `translateX(120%) → 0` + 淡入 | 520ms `cubic-bezier(.16,1,.3,1)` |
| 未读呼吸 | `scale 1 → 1.015 → 1` | 3.2s ease-in-out infinite（仅未读） |
| 拖动中 | `scale 1.03` + 阴影加深 | 160ms |
| 松手 | 回 `scale 1` | 260ms `cubic-bezier(.2,.8,.25,1)` |
| 拆封① | 封口盖 `rotateX(0 → -168deg)`，origin top | 320ms ease-in-out |
| 拆封② | 卡片 `translateY(28px) scale(.92)` → 归位 | 460ms `cubic-bezier(.16,1,.3,1)` |
| 拆封③ | 信封淡出 + 背景 blur 3px→7px | 460ms ease-out |
| 拆封④ | 正文逐段淡入，段间隔 90ms | 380ms × n ease-out |
| 落款（普通） | 淡入 + 上移 6px | 420ms |
| 落款（情书） | mask 从左往右擦出 | **1100ms** ease-out |
| 关闭 | `scale(1) → .96` + 淡出 | 260ms |
| 右键菜单 | `scale(.94) → 1` + 淡入 | 140ms |
| 收进右边栏 | 见 §一 三拍 | 320 + 400 + 180ms |

节制：同屏最多 1 个无限循环；只碰 `transform/opacity/filter/mask`；全部受 `reduce-ui-motion` 降级为 120ms 淡入。

## 八、情书软锁

第一次打开情书弹：`这封只写给你。确定现在看？[ 看 ][ 等会儿 ]`

- 只在第一次；点「看」后记 `unlocked_at`。
- 「等会儿」不算已读，封蜡仍实心。
- 不做 PIN。
